# Keyboard Shortcuts

The shortcuts below are the primary documented shortcuts. `Cmd` refers to the Command key on macOS; use `Ctrl` on Windows and Linux unless noted otherwise. Menu labels and shortcut handling may vary by platform.

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| New File | `Cmd+N` | `Ctrl+N` |
| Open File | `Cmd+O` | `Ctrl+O` |
| Open Folder | `Cmd+Shift+O` | `Ctrl+Shift+O` |
| Save File | `Cmd+S` | `Ctrl+S` |
| Quick Open | `Cmd+P` | `Ctrl+P` |
| Command Palette | `Cmd+Shift+P` | `Ctrl+Shift+P` |
| Format Document | `Cmd+Shift+I` | `Ctrl+Shift+I` |
| Quick Fix | `Cmd+.` | `Ctrl+.` |
| Show Problems | `Cmd+Shift+M` | `Ctrl+Shift+M` |
| Toggle Terminal | Ctrl + backtick | Ctrl + backtick |
| Toggle Sidebar | `Cmd+B` | `Ctrl+B` |
| Open Settings | `Cmd+,` | `Ctrl+,` |
| Quit BeagleEditor | `Cmd+Q` | `Ctrl+Q` |

## Navigation tips

- In Quick Open, type part of a file name, use the arrow keys to select a result, and press Enter to open it. Press Escape to close the picker.
- In the Command Palette, type a command name, navigate with the arrow keys, and press Enter to run it. Press Escape to dismiss it.
- If you forget a command shortcut, open the Command Palette and search for the action by name.

> **Note:** This list reflects the shortcuts currently registered by BeagleEditor. Monaco Editor also provides standard text-editing and navigation shortcuts; some may differ by operating system or keyboard layout.
