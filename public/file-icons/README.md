# File icons

The SVG file-type icons are bundled locally from these open-source icon themes:

- [vscode-icons](https://github.com/vscode-icons/vscode-icons) — MIT License; Copyright The vscode-icons Contributors.
- [Material Icon Theme](https://github.com/PKief/vscode-material-icon-theme) — MIT License; Copyright Philipp Kief and contributors.

The assets are stored locally so file icons render without a network connection. Some upstream filenames are renamed to semantic keys used by BeagleEditor. See each upstream repository for its license.
